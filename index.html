Wellness & OT-Informed Healthcare Cost Prediction

Data Science Portfolio Project | Raquel

Project Overview

This project investigates the drivers of healthcare insurance costs using interpretable regression modelling, nonlinear interaction effects, and structured model evaluation.

Findings are interpreted through an Occupational Therapy perspective, connecting statistical risk patterns to long-term functional burden and participation outcomes.

Technical Highlights

  • Exploratory Data Analysis (EDA)
  • Log-transformed regression modelling
  • Nonlinear and interaction effects (smoker × BMI)
  • Model comparison and evaluation metrics
  • Machine learning benchmark (Random Forest)
  • Ethical and population-level interpretation
